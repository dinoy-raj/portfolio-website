Here’s where developers translate those design decisions into the actual Android implementation. For multi-pane layouts, we can use the Material 3 Adaptive library or the appropriate Navigation 3 scene strategies.

For adaptive grids, Compose provides LazyVerticalGrid with GridCells.Adaptive. For constrained layouts, we can use widthIn. For keyboard focus and shortcuts, we have focusable, focusProperties and key event handlers.

And for mouse and trackpad, we can use hover interactions and pointer input APIs. The important thing is that developers shouldn’t invent the adaptive behaviour on their own.

They should implement the behaviour defined during product design.
