Now let’s connect those experiences to the implementation. We can use WindowInfoTracker to observe folding information. FoldingFeature tells us the fold’s orientation, state and bounds. For camera scenarios, we can use CameraX.

For picture-in-picture, Android provides PictureInPictureParams, and RemoteAction exposes custom actions. For launching content in an adjacent window, Android provides launch options and activity flags. We can support drag and drop through Compose APIs or platform helpers.

The important point: the platform provides the building blocks, but the product team still has to decide which experiences are meaningful.
