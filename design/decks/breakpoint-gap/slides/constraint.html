Mobile was always about constraints.
The new one is the window.

⏱ 35s

Historically, mobile design was largely about working within constraints. We had to deal with internet availability, battery consumption and memory limits. But today, the same app can run in many different window configurations.

A user can resize it, put it beside another app, fold the device, unfold it, or move between environments. So the question is no longer just how our app fits on a phone.

The question is: how does our app respond when the window changes?
