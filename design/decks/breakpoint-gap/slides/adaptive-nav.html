Navigation is another area where we often see apps simply stretch their mobile interface. On a compact screen, a bottom navigation bar makes sense because it’s easy to reach with the thumb.

But on a tablet, the same bar can consume unnecessary vertical space. A navigation rail is a better fit when more horizontal space is available. On larger windows, an expanded rail can show labels and more navigation context.

There’s no need to build a completely different navigation system for every device: we can use adaptive navigation patterns.
