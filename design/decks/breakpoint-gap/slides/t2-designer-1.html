Let’s translate Tier 2 into actual design responsibilities. Designers should decide how navigation changes as the window gets wider. They should specify when a grid introduces additional columns, and when a list-detail layout becomes appropriate.

They should also think about secondary interactions. A full-width button might make sense on a phone, but on a large display it can look disproportionate. Menus should appear close to the item that triggered them.

Images should scale proportionally instead of stretching. And designers should specify which elements can receive focus, how users move between them with Tab, and how interactive elements respond to hover.
