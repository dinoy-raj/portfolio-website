Designers have been shipping responsive designs for different widths on the web for years: either stretching to the full width or keeping a minimum width. Adaptive doesn’t mean we stop using responsive techniques.

It means we make meaningful structural decisions instead of simply stretching the existing UI. That brings adaptive layouts, adapting to device postures, making our UI hinge-aware, and deciding how each component behaves on each form factor: multiple panes, navigation that switches.

So building adaptive is a real mental-model shift in how we arrange the UI spatially for each constraint.
