Adaptive Starts in the Design System

Search

SearchView ↔ DockedSearchBar

Navigation

NavigationBar ↔ NavigationRail

Sheet

Bottom sheet ↔ side sheet

Dialog

Full-screen ↔ basic dialog

Context menu

Action sheet ↔ DropdownMenu

Toolbar

Docked toolbar ↔ floating toolbar
⏱ 50s

One thing I strongly believe is that adaptive behaviour should start in the design system. If every product screen independently decides how navigation, dialogs and sheets behave, we’ll end up with inconsistent experiences.

Instead, the design system should provide adaptive component definitions. Our navigation component should know how to present itself across window sizes. Our bottom sheet might become a side sheet when there’s enough space.

Search might change from a full-screen experience to a docked component. Dialogs and menus change their presentation too, and the toolbar goes from docked along the bottom to floating beside the content.

This way, adaptive behaviour becomes a shared product capability, rather than something every feature team has to reinvent.
